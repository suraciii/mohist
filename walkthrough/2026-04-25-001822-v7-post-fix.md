## entrypoint.sh 修复迭代

1. **初始修复**: 移除 CHLD trap + 移除 `exit_code == 143` 清洁退出 → 仍然退出
2. **根因发现**: mo-server 在 SIGTERM 后 exit 0，`wait` 返回 0 → "Server exited cleanly"
3. **第二次修复**: 只在 `shutdown=1` 时退出，其他情况一律重启 → 仍然退出
4. **根因发现**: `setsid` 使 server 运行在不同 session，`wait $SERVER_PID` 无法等待
5. **最终修复**: 移除 `setsid`，直接 background 运行 → ✅ 重启正常
