## 发现的问题

### 问题 #1: reopen 后 error 未清除 [中等]
- **现象**: Issue #1 在 opencode ENOENT 错误后 reopen，error 字段保留旧值，pipeline 不重试
- **根因**: reopen 只设置 status=active + resumePipeline，不清理 approvalState.error
- **证据**: API 返回 `approvalState.status: "error"` 但 `status: "active"`，pipeline 未重新运行
- **建议**: reopen 时清理 approvalState 或提供 `--retry` 选项

### 问题 #2: 容器内更新源码流程复杂 [低]
- **现象**: 需要 kill server → tar → rebuild → 手动启动 server，且 kill server 导致 entrypoint.sh 退出 → 容器停止
- **根因**: entrypoint.sh 的 `wait` 在子进程退出后结束
- **建议**: 添加 `mo server restart` 命令，或改进 entrypoint.sh 支持 `exec` 替换
