## 发现的问题

### 问题 #1: Agent 不提交代码到 git [中等] (v4 #5 复现)
- **现象**: Issue #1 build 完成后 worktree 新文件 untracked
- **根因**: opencode agent 未被指示或无法执行 git commit
- **证据**: 与 v4 完全相同的行为
- **建议**: Agent 或 build pipeline 应在完成 task 后提交代码

### 问题 #2: 容器停止需要 SIGKILL [低] (v4 #8 复现)
- **现象**: `podman stop` 的 SIGTERM 在 10 秒内未能停止容器
- **根因**: sleep infinity 不响应 SIGTERM
- **建议**: 使用 `sleep infinity & wait` 或添加 signal handler

### 问题 #3: Zombie 进程 [低]
- **现象**: 多个 [sh] defunct 进程
- **根因**: spawn 的 sh 子进程退出后未被 init 回收（容器 PID 1 是 sleep infinity，不是 init）
- **建议**: 使用 tini 或 dumb-init 作为 PID 1
