# Feature Specifications

The [product capability areas](../docs/vision.md#product-capability-areas)
explain the user goals. [Domain Analysis](../design/domain-analysis.md) assigns
the business rules to their owners.

Find a feature by its subdomain and name. Its `spec.md` defines behavior and
acceptance scenarios; its optional `design.md` explains mechanisms. Follow
direct dependency links when a task crosses feature boundaries.

For an example, start with [Session execution evidence](session/execution-evidence/spec.md).
It links to the Runner confirmation source and the activity presentation that
consumes it. For installation and daily operations, use the
[user guides](../docs/README.md).
