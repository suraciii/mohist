## Before You Start

Read the context-files. Understand the proposal (WHY), design (HOW), and specs (WHAT). Review the tasks file to see where this task fits in the overall plan.

## Implement

Make minimal, focused changes to complete this single task. Follow the task description and meet every acceptance criterion.

If this task references a spec requirement:
- Read the spec file and locate the requirement section
- Ensure every WHEN/THEN scenario in the requirement passes
- Also verify all acceptance criteria (supplementary checks)

If no spec reference, use acceptance criteria as the complete verification list.

## Verify

After implementing, run typecheck and tests to confirm nothing is broken. All acceptance criteria must pass.

## When Done

Stage and commit your changes. The commit message should start with the task ID.
