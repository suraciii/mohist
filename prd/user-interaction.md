# 用户交互

## 你的角色

你是**产品负责人**，不是程序员。

- 你决定做什么
- 你确认方案
- 你审查结果
- AI 负责实现

## 你需要投入的时间

```
假设一个需求从想法到合并需要 2 小时：

你的时间：
├── 描述想法: 2 分钟
├── 对话澄清需求: 30 分钟
├── 确认方案: 10 分钟
├── 审查结果: 15 分钟
└── 总计: ~1 小时

AI 自动执行的时间：
└── ~1 小时（你可以去做别的事）
```

## 你在哪个阶段参与最多

```
Draft    ██ 低      创建 Issue 就行
Explore  ████████ 高   和 AI 对话，把需求聊清楚
Plan     ████ 中      审查方案，确认可以开发
Dev      █ 低        AI 自己写，你忙别的
Verify   ████ 中      审查结果，决定合并
```

## 你怎么和 crawlph 交互

### 查看进度

```
$ crawlph status 42

Issue #42: 添加搜索功能
阶段: 开发中 (3/5 任务完成)

进度:
✓ 添加搜索索引
✓ 实现 SearchService  
✓ 实现搜索 API
● 添加搜索 UI (进行中)
○ 测试
```

### 追加指令

```
$ crawlph attach 42

> 搜索结果需要按相关度排序
> 退出
```

### 确认/合并

```
$ crawlph approve 42    # 确认方案，开始开发
$ crawlph merge 42      # 合并代码
```

## 你可以随时说

- **"可以规划了"** - 需求聊清楚了，开始定方案
- **"可以开发了"** - 方案没问题，开始写代码
- **"暂停"** - 先停一下
- **"继续"** - 恢复执行
- **"合并"** - 审查通过，合并代码
- **"取消"** - 不做了，关闭 Issue
