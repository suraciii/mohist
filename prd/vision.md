# 产品愿景

## 一句话描述

crawlph 是一条从想法到代码的流水线。

## 解决什么问题

```
传统方式:
你: "帮我加个搜索功能"
AI: (写代码...)
你: "不对，我要的是..."
AI: (改代码...)
你: "还是不对，需求是这样的..."
AI: (改需求...)
(循环往复，效率低)

crawlph:
你: 创建 Issue "加搜索"
AI: "搜索什么内容？要高亮吗？要分页吗？"
你: 回答问题
AI: (给出方案)
你: 确认
AI: (写代码)
你: 审查
(需求清晰，一次到位)
```

## 核心价值

- **需求先行** - 先聊清楚，再动手
- **自动推进** - 流水线自动跑，不用盯着
- **随时介入** - 你随时可以追加指令
- **清晰边界** - 你确认后，AI 才执行

## 边界

### 现在做的

```
Issue 创建 ──────────────────────────────────────▶ PR 合并
(想法)                                              (代码)
```

### 暂不做的

- 部署到生产
- 监控和告警
- 多人协作

### 未来可能做的

- 从想法到上线
- 团队协作
- 项目管理
