# 工作流

## 核心理念

crawlph 是一条从想法到代码的流水线。

```
你的想法 ──▶ crawlph ──▶ 合格的代码
```

## 五个阶段

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   1.Draft      2.Explore       3.Plan        4.Dev        5.Verify  │
│   ┌─────┐      ┌─────┐        ┌─────┐       ┌─────┐      ┌─────┐   │
│   │ 草稿 │ ───▶│ 探索 │ ─────▶│ 计划 │ ────▶│ 开发 │ ───▶│ 验证 │   │
│   └─────┘      └─────┘        └─────┘       └─────┘      └─────┘   │
│                                                                     │
│   "有个想法"    "聊清楚"        "定方案"      "做出来"     "没问题"   │
│                                                                     │
│                     ⏸              ⏸              ⏸               │
│                   你确认          你确认          你确认            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 你需要做什么

```
1. 创建 Issue，描述你的想法
       ↓
2. 和 AI 对话，把需求聊清楚
       ↓
3. AI 给出方案，你确认
       ↓
4. AI 写代码（你可以随时介入）
       ↓
5. 审查结果，决定合并
```

## 两个确认点

```
Explore ──▶ Plan ──▶ Dev ──▶ Verify
              │               │
              ▼               ▼
         "可以开发了"      "合并"
```

- **Plan → Dev**：方案确认后，AI 开始写代码
- **Verify → Done**：审查通过后，合并代码

## 随时可以介入

你不是旁观者。在任何阶段：

- 查看进度
- 追加指令
- 要求暂停
- 要求回退
