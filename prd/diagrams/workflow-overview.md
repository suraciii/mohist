# 工作流概览

## 产品理念：CI 流水线，但用于软件开发

```
传统 CI:   代码 ──▶ 构建 ──▶ 测试 ──▶ 部署

crawlph:  想法 ──▶ 需求 ──▶ 方案 ──▶ 代码 ──▶ 验证 ──▶ 合并
```

## 核心流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                        你的想法                                     │
│                           │                                         │
│                           ▼                                         │
│   ┌─────────────────────────────────────────────────────────────┐   │
│   │                      crawlph 流水线                          │   │
│   │                                                             │   │
│   │   Draft ──▶ Explore ──▶ Plan ──▶ Dev ──▶ Verify ──▶ Done   │   │
│   │             │           │         │           │             │   │
│   │             ▼           ▼         ▼           ▼             │   │
│   │          和你对话     你确认    AI执行      你审查          │   │
│   │                                                             │   │
│   └─────────────────────────────────────────────────────────────┘   │
│                           │                                         │
│                           ▼                                         │
│                      合并的代码                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 每个阶段发生了什么

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Draft (草稿)                                                        │
│  ────────────                                                        │
│  你: 创建 Issue，写个想法                                            │
│  AI: (等待)                                                          │
│  产出: 一个草稿 Issue                                                │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Explore (探索)                                                      │
│  ──────────────                                                      │
│  你: 回答 AI 的问题，澄清需求                                         │
│  AI: 主动提问，帮你理清思路                                           │
│  产出: 清晰的需求 + 验收标准                                          │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Plan (计划)                                                         │
│  ───────────                                                         │
│  你: 审查方案，确认没问题                                             │
│  AI: 分析代码库，给出技术方案和任务分解                                │
│  产出: 技术方案 + 任务清单                                            │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Dev (开发)                                                          │
│  ───────────                                                         │
│  你: (可以去做别的事，也可以随时查看进度/追加指令)                      │
│  AI: 逐个完成任务，写代码，创建 PR                                     │
│  产出: 代码 + PR                                                     │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Verify (验证)                                                       │
│  ──────────────                                                      │
│  你: 审查 PR，决定是否合并                                            │
│  AI: 运行测试，自动审查代码质量，修复问题                               │
│  产出: 合格的 PR                                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 你的两个决策点

```
                        决策点 1              决策点 2
                           │                     │
                           ▼                     ▼
Draft ──▶ Explore ──▶ Plan ──▶ Dev ──▶ Verify ──▶ Done
                          │                  │
                     "可以开发了"          "合并"
                          │                  │
                     方案OK，开始写        审查OK，合并代码
```

## 如果发现问题

```
在任何阶段，你都可以说：

"回到探索" ──▶ 需求理解错了，重新聊
"回到计划" ──▶ 方案有问题，重新定
"暂停"     ──▶ 先停下来
"取消"     ──▶ 不做了
```
