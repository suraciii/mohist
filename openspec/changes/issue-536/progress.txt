## Codebase Patterns

- `MohistDbContext` exposes `WorkflowRuns` (rows) and `WorkflowRunTaskMaps` (`IDbContextFactory<MohistDbContext>` for hand-rolled tests). `ETag` is a shadow property accessed via `db.Entry(row).Property<long>("ETag")`. Bump pattern: `etag.CurrentValue = etag.OriginalValue + 1`.
- Spec test scaffolding (`TestSqliteDatabase.CreateMigrated`, `TestDbContextFactory`, `NullDispatchGrainFactory`, `Mohist.Server.Infrastructure.BackgroundTaskLauncher`, `RecordingEventStore`) lets the upgrader and store tests run without an Orleans silo.
- `MigrateLegacyWorkflowRunJson` lives on `WorkflowRunStateDataUpgrader` and stays a public static entry point — call sites in tests still call it directly. T-002 removes read-path call sites; this task only relocates and wires.
- WorkflowRun reads use `JSON.Deserialize<WorkflowRun>` directly (no legacy converter in `WorkflowRunStore.Deserialize`). Read path remains correct (and redundant) after T-001 because the read path no longer invokes the converter — only `WorkflowRunStateDataUpgrader` does.
