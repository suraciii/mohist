## 注意点 / 经验

- jsdom 下无法测量真实 `scrollWidth/clientWidth`，所以 jsdom 套件只能作为结构契约代理；像素级 `scrollWidth <= clientWidth` 校验按 design 留给真实浏览器（Playwright a11y 配置已经存在，但本任务不在范围内引入新 e2e）。
- 给 header container 加 className 选择器时，`md:flex-row` 等带冒号需要 CSS 转义（`.flex.flex-col.gap-4.md\\:flex-row`），但用最稳的稳定部分（`.flex.flex-col.gap-4`）就够了——冒号类在断言里通过 `classList.contains('md:flex-row')` 直接读。
- 长标题（中英文）都是字符串字面量放进单测，不需要 mock `useEpic` 返回值结构——`title` 字段直接传给 h1。

## T-002 — Header displays real Epic number on project-prefixed routes

完成的事：

- 根因修复：`Header` 在 `<Routes>` 之外挂载，`useParams()` 返回空，因此旧版 `params.id` 永远为空、`useEpic('')` 没数据、`Epic #${epic?.number ?? ''}` 退化为裸 `Epic #`。改为从 `useLocation().pathname` 解析 `.../epics/<seg>` 段，统一两条重复的「firstSegment 分支」与「section 分支」逻辑。
- 新增辅助：
  - `findEpicIdSegment(pathname)`：扫描路径分段、找到 `epics` 段后返回其下一个非空段；对 `/epics/:id` 与 `/:projectName/epics/:id` 都生效；空段、`/epics`（无后续段）返回 `null`。
  - `formatEpicTitle(loading, epic, fallback)`：加载中 `Epic #…`、有 number `Epic #<number>`、无 number 但有路径段则回退到稳定短前缀（id 前 8 字符），否则 `Epic`——永不出裸 `Epic #`。
- `usePageTitle` 里 `useEpic(epicIdSegment ?? '')` 仍保持条件启用（`enabled: !!id`，空 id 不触发请求）；hook 顺序稳定。
- `firstSegment === 'epics'` 内层结构调整：segments.length > 1 才走 `formatEpicTitle`，否则 `return 'Epics'`（保留 `/epics` 列表页标题）。
- 新增 7 个测试：
  - 生产 mount（Header 在 `<Routes>` 之外）+ 项目前缀路由 → `Epic #3`。
  - 生产 mount + 旧 `/epics/<id>` 路由 → `Epic #7`。
  - 生产 mount + 加载中 → `Epic #…`。
  - 生产 mount + 加载完成但 `number: null` → `Epic #epic-fal`（id 前 8 字符）。
  - 旧路由下 + 加载完成但 `number: null` → `Epic #epic-fal`。
  - `/epics` 列表页 + `useEpic` 返回 `data: undefined, isLoading: false` → 不出现裸 `Epic #`。
- Header 测试 21/21 通过；全 web 包 2432 通过（1 个 skip 与本任务无关）。
- typecheck 通过。

## 注意点 / 经验（T-002）

- jsdom 下 `useParams()` 在 `<Routes>` 之外 mount 的组件永远返回 `{}`——这是 React Router v7 的预期行为，不是 bug。修复要绕开它：用 `useLocation().pathname` 自己解析路径段。这同时把 issue 详情页（已有路径分段兜底 `section.split('/')[2]`）和 epic 详情页的解析逻辑对齐成同一来源。
- 解析路径段时一定要在循环里加 `i < segments.length - 1` 上界，否则 `/epics`（单段）会让 `segments[i + 1]` 变成 `undefined`，误匹配到空 fallback；当前实现直接返回 `null` 让上游分支走列表页路径。
- `useEpic` mock 不区分空 id/有 id，但 `enabled: !!id` 让空 id 永不触发请求；mock 在所有路由都安全返回，可以无条件调用 `useEpic(epicIdSegment ?? '')`。
- 「永不出现裸 `Epic #`」需要双重保护：`formatEpicTitle` 在没有 number 也没有 fallback 时返回 `Epic`（去掉 `#`），而不是 `Epic #`。
- 单测里同时保留 `renderHeader`（生产 mount，Header 在 `<Routes>` 之外）和 `renderHeaderWithRoute`（Header 嵌在路由 element 里）两种 fixture：前者证明根因已修，后者防回归「Header 嵌在 `<Routes>` 内时变好但生产挂载坏掉」。
- 一个工作流任务 = 一个 commit，commit 信息以 `T-002` 开头。
