## Codebase Patterns

- Issue affiliations are stored on the child aggregate and projected to `IssueRow`; aggregate events are persisted by `IssueStore` in the same transaction.
- HTTP create is coordinator-backed, so parent data must travel through `RepositoryCommandPayload.Create`, `IIssueBindingTarget`, and `IssueBindingParticipantProxy`.
- Repository-bearing PATCH uses the coordinator-backed `Change` payload; direct PATCH uses `UpdateIssueData` and both paths need parent presence semantics.
