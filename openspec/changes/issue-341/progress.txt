## Codebase Patterns

- jsdom cannot lay out: stickiness is asserted via `data-sticky="true"` + className contains `sticky` + first-child-of-scroll-container (mirrors `SessionPage.sticky.test.tsx:445` / `SessionDetailShell.tsx:289-290`).
- The scroll container for the detail page is `issue-detail-page-container` (`flex-1 min-w-0 overflow-y-auto`). Sticky positioning is relative to this container, not the window.
- The runtime situation is built up via `deriveRuntimeDecision` (single source of truth); presentation layers must consume `decision.summary`/`decision.currentTask` verbatim and never re-classify.
- Tone map lives in `pills.tsx` (`runtimeSummaryPresentation`) — `StatusHeadline` reuses a parallel map keyed off the same `RuntimeSummary` values but with the `*-subtle` fill + icon + border to layer as the heaviest tier.
- `WorkflowInterrupted` "static" card is removed because `deriveRuntimeDecision.blockedReason` already surfaces interrupted health in the headline/surface; removal is the D5 outcome, not a regression.
