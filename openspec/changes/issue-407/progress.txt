## Codebase Patterns

- AgentSession state is persisted as JSON by AgentSessionStore. Optional Runtime parameters deserialize old state as null, and reads do not save or rewrite that state.
- OpenAgentSessionCommand.AgentRuntime is authoritative when AgentSessionGrain creates a session. AttachPhysicalSession derives lineage and event Runtime from the persisted current binding, so it cannot relabel a legacy binding.
- AgentSessionExtensions.IsRuntimeSessionMissing owns the binding check and accepts the backend-registration predicate. AgentSessionGrain currently registers only `opencode`; adding another runtime later must update that authority rather than infer a runtime from runner presence.
- Compact and Reset enforce runtime presence inside the grain. Follow-up performs the same grain preflight before any SignalR send. Routes map RuntimeSessionMissingException to HTTP 409 `runtime_session_missing` with the stable sessionId and a Reset hint.
- JSON.Options omits null values, so legacy AgentSessionRuntimeBound events do not expose a synthetic Runtime field.
