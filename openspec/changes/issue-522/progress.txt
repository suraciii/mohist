## Codebase Patterns

- AgentSession child records are persisted in the grain state snapshot; Orleans serialization requires arrays for single-item InputIds values rather than collection-expression read-only lists.
- Follow-up reservations distinguish joining an active turn from starting an idle turn. Only idle-start follow-ups mint and persist a new input/turn pair before Runner dispatch.
- Explicit Runner rejection cleans up the pre-dispatch queued follow-up record so existing retry behavior remains intact; uncertain dispatch failures retain the record.
