## Codebase Patterns

- `TranscriptAccumulator.EventTypes` is the canonical allow-list for AgentSession runtime ingress and transcript persistence.
- Terminal AgentJob delivery is persisted as `TranscriptPartTypes.SessionActivity`; its `operationId`/delivery id is the transcript correlation key, so duplicate runtime delivery remains one part while `RawEventCount` records both observations.
- Project and Issue AgentOps feeds query persisted `session.activity` parts directly. The Issue feed additionally requires routed AgentJob lineage and a canonical `agent-job:{id}:terminal` delivery id.
