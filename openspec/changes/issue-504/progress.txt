## Codebase Patterns

- WorkflowRun metadata is an Orleans generated record; new fields must be appended after field IDs 0..3.
- SQLite WorkflowRuns projections are generated columns and the profile-binding FK uses `(MetadataProjectId, WorkflowProfileIdKey)`.
- Spec tests use `TestSqliteDatabase.CreateMigrated()` and in-process grains; no physical database or external dependency is needed.
