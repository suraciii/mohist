## Codebase Patterns

- Preset resources use a separate `presets/` content root, while asset lookup reuses the packaged sibling-root fallback behavior from `SkillAssetRootResolver`.
- `PresetCatalog` accepts an explicit root for FakeFileSystem tests and returns `PresetCatalogResult` with available names for unknown presets.
- The manifest stores file references; response prompt files are read verbatim so `{{event.*}}` placeholders remain unrendered.
