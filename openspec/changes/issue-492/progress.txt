## Codebase Patterns
- OpenCode SDK session calls use `{ sessionID, directory }` plus `{ throwOnError: true }`, matching `runtime/opencode/turn.ts`.
- Runtime resolve results carry the physical active-turn snapshot: OpenCode derives it from `session.status` (`undefined`/`idle` is idle), while Pi reads the cached handle's `isStreaming` getter.
- `BindingProbeResult` represents presence as `{ ok: true, activeTurn }`; only a failed probe with `kind === "missing-session"` authorizes candidate creation.
