## Codebase Patterns
- `MohistCliCommands.Build` constructs the authoritative `System.CommandLine` tree, then installs local help and calls `CommandPresentations.AttachTo` on the same `Command` instances.
- `CommandHelpRenderer` derives usage, arguments, visible options, and descriptor-backed JSON fields from live command objects; hidden commands/options are filtered at render time.
- Existing CLI help tests use `CliTestFactory.Create(activeProjectId: null)` with recording/rejecting HTTP handlers and assert no requests for help.
