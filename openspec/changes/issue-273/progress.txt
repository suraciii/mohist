## Codebase Patterns

- Workflow profile YAML lives under `packages/server/src/Mohist.Server/Issue/Services/WorkflowProfiles/`.
- Server-side profile assertions are in `packages/server/tests/Mohist.Server.Tests/Specs/Issue/Profile/MohistPrIssueWorkflowProfileSpecs.cs`.
- `npm test` at server root runs `dotnet test Mohist.sln`; workspace vitest failures are pre-existing environment issues in this repo.
- Runner action tests for git operations use `setPushGitRunnerForTest` to inject a fake git runner and capture command history.
