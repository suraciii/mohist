### Codebase patterns confirmed for later tasks

- React 19 + `useRef<T>(null)` types as `RefObject<T | null>`. To match a `RefObject<T>` signature verbatim, `useRef<T | null>(null)` and `return ref as React.RefObject<T>` works (strict-mode safe; the runtime value really is `T | null` but the consumer never reads it before the panel renders).
- tsconfig enables `noUnusedLocals`. A "shared" `let` binding that one render path writes to and test code reads in `act()` needs a local `const` copy inside the helper (TS will not narrow `let`s across functions).
- The hook is purely behavioral (no JSX, no testid), so its move does not touch the density test's structural query — confirmed by rerunning the full issue-detail suite (5 files / 75 tests green).

### Gotchas

- Vitest's `// @vitest-environment jsdom` is needed because the hook attaches a real DOM listener.
- `vi.spyOn(document, 'addEventListener'|'removeEventListener')` survives the hook's effect cleanup without interfering with the fake timer, so the listener-removal test stays deterministic (no wall clock).
