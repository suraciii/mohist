## Codebase Patterns

- Computed columns are declared as nullable properties on the row class and configured in `MohistDbContext.OnModelCreating`.
- Use `COALESCE(camelCase, PascalCase)` to tolerate both casings in `State` JSON.
- For SQLite, use `stored: true` for columns that will be joined/selected heavily; virtual columns are acceptable for indexed status columns but not for join columns.
- Migrations are generated with `~/.dotnet/tools/dotnet-ef migrations add <Name>` from `packages/server` using the server project as both `--project` and `--startup-project`.
- In-memory SQLite integration tests use `Microsoft.Data.Sqlite.SqliteConnection("Data Source=:memory:")` + `DbContextOptionsBuilder< MohistDbContext>().UseSqlite(connection)` + `db.Database.Migrate()`.
