## Codebase Patterns

- RunnerHost owns one ActionRegistry instance and passes that exact instance to WorkExecutor; registration and heartbeat state project its catalog from the same registry.
- Runner catalog DTOs use arrays for deterministic ordering. C# ActionCatalogInput.Default is the only generic JSON leaf and remains nullable so omitted static defaults stay absent on the wire.
- RunnerGrain clones reported catalog data before retaining it and mirrors the retained RunnerInfo into the online global registry.
