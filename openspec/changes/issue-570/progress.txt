## Codebase Patterns

- WorkflowRun is persisted as JSON through WorkflowRunStore; additive nullable properties on TaskRun and StageRun survive activation without a schema migration.
- Runner presence closeout enumerates running workflow assignments and first calls ObserveAgentRunnerDisconnectedAsync. Only a stale response falls through to ordinary-work interruption recording, preserving AgentResultSettlement arbitration.
- Workflow reminder reconciliation follows the existing AgentResultSettlement pattern: owner grain registers a durable Orleans reminder from the persisted absolute deadline and re-runs the check on activation.
- Workflow status remains Running and TaskRunStatus remains Running while WorkInterruption is present; no Interrupted enum is introduced.
