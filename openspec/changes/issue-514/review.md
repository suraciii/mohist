# Review: Issue 514

## Findings

1. **P0 - Successful Slack setup cannot verify its required scopes.** `SlackSetupVerifier` reads required scopes from `bots.info` ([SlackSetupVerifier.cs:48](../../../packages/server/src/Mohist.Server/Slack/SlackSetupVerifier.cs#L48)), but that response does not provide an installed App's OAuth scopes. `SlackBotInfo.Scopes` is therefore null for a real Slack response, making every required scope appear absent and moving the Connection to `FixSlackSetup` ([SlackSetupVerifier.cs:49](../../../packages/server/src/Mohist.Server/Slack/SlackSetupVerifier.cs#L49)). The same method passes `auth.test`'s `user_id` to `bots.info` ([SlackSetupVerifier.cs:41](../../../packages/server/src/Mohist.Server/Slack/SlackSetupVerifier.cs#L41)), while that API requires the Bot ID rather than the bot user's ID. Consequently a real configured Connection cannot reliably reach `ClaimOwner`. Model and retrieve the correct Slack identifiers and use an API contract that actually exposes the granted scopes; add integration-shaped fake responses matching Slack's real payloads.

2. **P1 - Terminal Slack messages discard the actual result.** On terminal completion, the Job always creates exactly `"Task completed."`; failure always creates `"Task failed. Review the job in Mohist."` ([AgentJobGrain.cs:1304](../../../packages/server/src/Mohist.Server/Agent/Grains/AgentJobGrain.cs#L1304)). Neither message uses the terminal `message`, `output`, failure reason, artifacts, or any derived next step that was persisted immediately above ([AgentJobGrain.cs:1296](../../../packages/server/src/Mohist.Server/Agent/Grains/AgentJobGrain.cs#L1296)). This does not satisfy the DM-result contract requiring a user-consumable conclusion, evidence, and next step without leaving Slack. Render a redacted, bounded summary from authoritative terminal facts and test successful, failed, and unknown outcomes.

3. **P1 - The AgentJob aggregate synchronously writes provider infrastructure.** `AgentJobGrain` directly calls `SlackOutboxStore.EnqueueRequiredAsync` ([AgentJobGrain.cs:1554](../../../packages/server/src/Mohist.Server/Agent/Grains/AgentJobGrain.cs#L1554)) after saving its own terminal state. This crosses the AgentJob aggregate boundary in the same synchronous flow, contrary to the required durable-event handoff for cross-aggregate progression. It also forced an optional dependency solely to keep unrelated grain test silos activatable ([AgentJobGrain.cs:62](../../../packages/server/src/Mohist.Server/Agent/Grains/AgentJobGrain.cs#L62)). Emit a durable terminal delivery event from the Job, and have a Server-infrastructure handler idempotently create the outbox record. The handler should own retry and preserve the current stable dispatch reference.
