## Codebase Patterns

- Issue 453 owns the ordered `IssueDecisionAction` descriptors and `IssueDecisionActionController`; approval composition must consume those values rather than derive a second action model.
- `useIssueWorkflowArtifacts` keeps the existing HTTP parameters and now accepts an optional run scope only for the TanStack Query key.
- `ArtifactTextContent` is shared by the dialog and inline review package; Markdown uses `MarkdownReader`, while other recorded text stays raw in a wrapping `pre`.

## T-002

- Added a package-local desktop-only approval keydown hook. It binds only enabled `a`/`m` actions, ignores editable targets, modifiers, repeats, and pending controller state, and removes its listener when the package or viewport/state changes.

- Added focused component tests and a controlled browser scenario covering approval shortcuts, editable-field safety, hints, send-back Command+Enter, comment submission, invalid/pending guards, plain Enter, and one request per keypress.
