  snapshot — recovery/replay robustness rationale documented in the
  `Fingerprint` XML comment + design D2).
- `BuildDispatch` composes the read-only background into the
  dispatched `with.prompt` via `AgentStartupContextComposer`; resolves
  Instructions / Runtime / Model / Variant / Skills remain
  unchanged.

  `InvalidOperationException`.
