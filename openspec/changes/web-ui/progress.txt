## [2026-04-05] T-013: Implement SSE client and real-time updates

**Status**: Completed

**What was done**:
- Created `packages/cli/web/src/hooks/useSSE.ts`: SSE client hook using native `EventSource` API
  - Connects to `/api/events?projectId=xxx` with current project ID
  - Listens to all 6 event types: stage_changed, comment_added, agent_started, agent_completed, agent_error, approval_requested
  - Automatic reconnection after disconnect (3s delay)
  - Closes old connection and creates new one when projectId changes (project switch)
- Integrated with TanStack Query cache invalidation:
  - stage_changed → invalidate ['issues'] (refreshes kanban + detail pages)
  - comment_added → invalidate ['issues'] (comments are embedded in issue responses)
  - agent_started/completed/error → invalidate ['agent-status'] + ['issues']
  - approval_requested → invalidate ['issues']
- Wired into `App.tsx`: `useSSE(projectId)` called in `AppContent` with project from context
- The existing `useAgentStatus` refetchInterval (5s) can remain as fallback; SSE provides instant updates

**Key learnings**:
- `EventSource` auto-reconnects natively for connection errors, but explicit error handling with `es.onerror` + manual reconnect gives more control (avoiding duplicate connections)
- Comments are embedded in the issue response, so invalidating ['issues'] prefix is sufficient for both kanban and detail page comment refresh
- The `useSSE` hook must be placed inside `ProjectProvider` (not alongside it) since it depends on `useQueryClient` and `useProject`
