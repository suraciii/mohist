Extended `runAcpOneshot` signature with `issueId` and `workflowLogRepo` parameters. The sessionUpdate handler now: (1) keeps existing agent_message_chunk → agentText concatenation, (2) persists every event type to workflow_log via `WorkflowLogRepo.insert()`, (3) wraps each event in try/catch to avoid one bad event killing the spawn.

**Learnings**:

- Cast `update as unknown as Record<string, unknown>` needed because ACP SDK types are complex discriminated unions, but `WorkflowLogRepo.insert` accepts `object`
