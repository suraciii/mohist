## Codebase Patterns
- Workspace API routes resolve the run-owned repository/workspace context and delegate diff, commits, commit diff, status, file content, and cleanup through `IRunnerWorkspaceClient`; route specs control `FakeRunnerWorkspaceClient` directly.
- Runner workspace transport DTOs belong beside `IRunnerWorkspaceClient` in `Runner/Services/SignalR`, not under the deleted Server-local workspace adapter.

- Added 5 EventBusTests covering: default identity equals the runtime full type name; explicit identity overrides it; explicit identity is preserved on the record; `AddCloudEventHandlers` honors `SubscriptionAttribute.Identity` when declared; it falls back to the runtime full name when omitted.
- Added a dedicated `EventDispatcherIdentitySpecs` file (4 tests) for the regression surface so `EventDispatcherSpecs` stays under its size ratchet baseline: dead-letter rows record the explicit identity verbatim; the default identity contract is unchanged for handlers without an explicit identity; a row persisted with a pre-relocation identity redelivers to the relocated handler; rows whose legacy identity has no matching subscription still surface the existing "not registered" failure.
