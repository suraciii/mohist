## ADDED Requirements

### Requirement: Saving issue workflow YAML synchronizes future workflow run definition only
When an issue has an active workflow run, saving issue workflow profile YAML SHALL synchronize the active `WorkflowRunProfile` with the updated normalized workflow definition for future uninitialized stages. Already initialized stage tasks and checks SHALL be preserved and SHALL NOT be regenerated by saving YAML.

#### Scenario: Active run profile is synchronized
- **WHEN** an issue has an active workflow run and the issue workflow profile YAML is saved successfully
- **THEN** the active `WorkflowRunProfile` is updated to the new normalized workflow definition
- **AND** future uninitialized stages use the updated definition when they are initialized

#### Scenario: Initialized stage work is preserved
- **WHEN** an issue has a stage that has already been initialized before workflow YAML is saved
- **THEN** that stage keeps its existing initialized tasks and checks
- **AND** saving workflow YAML does not regenerate or replace that initialized stage work

#### Scenario: Next stage initialization uses updated definition
- **WHEN** a later stage has not yet been initialized at the time workflow YAML is saved
- **THEN** `InitializeStage` uses the updated workflow run profile definition when that later stage is initialized
