## Codebase Patterns

- **DTO placement**: Agent-usage DTOs live in `AgentSessionReadModels.cs` alongside other session read models.
- **Querier methods**: `AgentSessionQuerier` in the `Workflow.Services.Sessions` namespace handles agent-session queries.
- **Db queries**: Use `IDbContextFactory<MohistDbContext>` + `AsNoTracking()` for read-only queries.
- **Issue access**: Done issues with `CompletedAt` can be queried via `IssueRowMapper.Deserialize()` after loading `IssueRow` rows from the database.
- **Session row CreatedAt**: The `AgentSessionRow.CreatedAt` DB column is the authoritative timestamp for session ordering; `ListByLabelsAsync` with `from`/`to` filters on this column.
- **Computed columns**: `LabelProjectId` on `AgentSessions` is a stored computed column from `State` JSON.

## T-001 Decisions & Gotchas

- **Pre-window spend via separate query**: Keep `GetUsageTimeseriesAsync` loading only window sessions (with `from`/`to`), and add a separate `ComputePreWindowSpendAsync` that queries `WHERE LabelProjectId = @p AND CreatedAt < @rangeFrom`. Merging both into one pass (loading all sessions) changes existing behavior subtly.
- **Pre-window shipped via IssueRow + IssueRowMapper**: Count done issues with `CompletedAt < rangeFrom` by loading `IssueRow` rows directly via `_dbFactory`, deserializing with `IssueRowMapper.Deserialize()`, and filtering on domain `Issue.Status == IssueStatus.Done && Issue.CompletedAt.HasValue`.
- **Null-vs-zero semantics**: `CumulativeCost` is null when `cumulativeSamples == 0` (no sessions with usage up to that day). `CostPerShip` is null when `cumulativeShipped == 0`. Both directly serialized via `double?` in System.Text.Json.
- **Currency propagation**: Pre-window currency can be null; must also check in-window buckets' `CostCurrency` when computing cumulative series.
- **Test time-dependence**: Tests that use `DateTime.UtcNow.Date.AddDays(-N)` can cross UTC midnight between session insertion and API handler execution, causing off-by-one bucket indices. Fix: call the API first to get `response.RangeFrom`, then use `rangeFrom.AddDays(K)` for session placement.
- **SampleCount on UsageBucketData**: Added to track per-bucket session-with-usage count for null-vs-zero semantics.
- **UsageBucketData unchanged DTO**: `SampleCount` is internal only; `UsageBucketDto.ToDto()` does not expose it.

## T-002 Decisions & Gotchas

- **BarSeries uses SVG rect with scaleY transform**: Each rect is drawn at full plotHeight and uses CSS `transform: scaleY(ratio)` with `transformOrigin` set to pixel coordinates at the bottom of the bar. This avoids animating `height` — only `transform` animates.
- **Bar rect has `rx={1}`**: Tiny rounding to avoid sharp tops on zero-scale bars.
- **Axis position uses `plotWidth`**: ChartAxes needs `plotWidth` to compute the right-axis X coordinate (axisX = plotX + plotWidth). Forgot to include it in the initial interface; caught by typecheck.
- **useReducedMotion reads matchMedia on mount + listens for changes**: The hook reads the initial value in a `useState` initializer, then subscribes to `change` events. Test stub was extended with a `_reducedMotionOverride` module variable so individual tests can call `setPrefersReducedMotion(true/false)`.
- **`setPrefersReducedMotion` is reset in afterEach**: The global `afterEach` in `setup.ts` resets `_reducedMotionOverride = undefined` so reduced motion doesn't leak between tests.
- **Legend uses tiny inline SVGs for shape swatches**: Bar shape = `<rect>`, line shape = `<polyline>` with marker circles. These are `aria-hidden="true"` since they're decorative.
- **ChartLegend hidden for single series**: The `ChartLegend` component returns `null` when `entries.length <= 1`, complying with the spec requirement of rendering a disambiguated legend only when > 1 series exists.
- **Test isolation via `screen.getByTestId('bar-series').children`**: Using `react-testing-library` `container` for queries can pick up stale DOM in shared vitest forks when `maxForks=1`. Scoping within the `g` element's children property avoids cross-test pollution.
- **ChartContainer uses min-h-[200px]**: Loading/error/empty states get a minimum height to avoid layout shift when content resolves.

## T-003 Decisions & Gotchas

- **useAgentUsage hook mirrors cost-rollup**: Same projectApiPath fetcher, same staleTime (60_000), same query key pattern `['agent', 'usage', projectId]`.
- **Chart composes dual-axis manually**: BarSeries is used for bars on the left axis; a separate `<ChartAxes side="right">` renders the cost-per-ship axis. When `cumulativeCostPerShip` is null/absent (old server), no right axis or trend line renders.
- **Axis label colors match series**: Left axis uses `stroke-chart-2`/`fill-chart-2` (bar color), right axis uses `stroke-chart-5`/`fill-chart-5` (trend color). Axis title texts are placed as `<text>` elements above each axis, also token-colored.
- **Zero-cost bar**: A bucket with `costAmount: 0` renders a `<rect>` with `scaleY(0)` — rect is present (not omitted), zero height. BarSeries handles this via its all-zero case.
- **Trend line null handling**: `LineSeries` accepts `(LinePoint | null)[]` and filters nulls for path building. This is what the spec requires for "skip null/undefined points" — a null entry produces no marker for that day.
- **Genuine zero trend value**: `costPerShip: 0` is not null, so `LinePoint` is emitted with y mapped to the bottom of the plot area (value 0 renders at origin). Distinguishable from null (no point).
- **Empty state detection**: Chart shows empty when `buckets.length === 0`. The server always returns 7 buckets (even for zero-spend projects), so this guard is defensive.
- **ChartInner doesn't use useReducedMotion directly**: BarSeries and LineSeries already import and use `useReducedMotion` internally. The host component doesn't need to duplicate.
- **ProductivityZone test needed CostTrendChart mock**: Since CostTrendChart imports `useAgentUsage` from `entities/agent` (which uses QueryClientProvider context), existing tests that mock child components individually needed a new mock entry for `CostTrendChart`.
- **DashboardPage test needed useAgentUsage mock**: The DashboardPage test mocks `entities/agent` but only listed `useAgentStatus` and `useCostRollup`. Added `useAgentUsage` to prevent `No QueryClient set` error when CostTrendChart mounts inside ProductivityZone.
