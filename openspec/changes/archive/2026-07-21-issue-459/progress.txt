## Codebase Patterns

- `AgentSessionQuerier.FindCurrentSessionAsync` is the active-run-only resolver shared by issue-scoped commands; historical fallback must not be added there.
- Issue-scoped metadata and transcript reads can reuse `AgentSessionQuery.FirstByLabelsAsync` with `CreatedDescending`; persisted workflow labels provide project, issue, source kind, and session name boundaries.
- Metadata JSON exposes the logical session identity as `id`; transcript runtime filtering operates on transcript-turn `RuntimeSessionId` within that logical session.
