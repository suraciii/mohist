## Codebase Patterns

- **Route group pattern**: All agent routes live under `/api/projects/{projectRef}/agent` via `app.MapGroup(...).AddEndpointFilter<ProjectResolutionEndpointFilter>()`. Use `context.GetResolvedProject()` to access the resolved project.
- **DTOs**: New DTOs go in `AgentSessionReadModels.cs` under `Mohist.Server.Workflow.Services.Sessions`. Use `sealed record` with positional parameters. JSON serialization defaults to camelCase.
- **Querier pattern**: Query methods live in `AgentSessionQuerier.cs`, delegating to `AgentSessionQuery` for DB access. The querier is registered as scoped in `MohistServiceRegistration.cs`.
- **AgentSessionQuery**: `ListByLabelsAsync` accepts labels dict, order, limit, and now optional `from`/`to` DateTime filters on `CreatedAt`. Callers should use named parameters for `ct` to avoid positional issues.
- **Usage extraction**: Always use `AgentSessionJsonHelper.Usage(s)` to get `AgentUsageSummary` from a session — this is the single definition shared across the codebase.
- **Session creation for tests**: Use `AgentSessionJson.JsonOptions` to serialize domain `AgentSession` objects. Set both `Status.CreatedAt` and `row.CreatedAt` to the same value for consistent bucketing.
- **Integration test pattern**: Tests use `[Collection("MohistIntegration")]`, `MohistIntegrationFixture`, `ApiTestClient` extension methods (`GetDataAsync`, `PostDataAsync`, `PostOkAsync`). Trait attributes: `[Trait(Traits.Speed.Name, Traits.Speed.Integration)]`, `[Trait(Traits.Sut.Name, Traits.Sut.Api)]`.

## Task T-001: Server: time-bucketed usage aggregation endpoint
- What was implemented:
  - Added optional `DateTime? from` and `DateTime? to` parameters to `AgentSessionQuery.ListByLabelsAsync` for time-range filtering on `AgentSessionRow.CreatedAt`.
  - Added `AgentUsageTimeseriesDto` and `UsageBucketDto` record types to `AgentSessionReadModels.cs`.
  - Added `GetUsageTimeseriesAsync(projectId, ct)` public method to `AgentSessionQuerier` that:
    - Computes a fixed 7-day UTC range (rangeTo = UtcNow.Date + 1 day, rangeFrom = rangeTo - 7 days).
    - Queries sessions by project label within that range, ordered CreatedAscending.
    - Buckets each session's `UsageSummary` (via `AgentSessionJsonHelper.Usage`) by `CreatedAt` into 7 daily buckets.
    - Fills all 7 buckets (zero totals for empty days); sessions without usage are skipped via `HasUsage` check.
    - Echoes first non-null `costCurrency` per bucket.
  - Added `group.MapGet("/usage", ...)` route to `AgentRoutes.cs` — delegates to `GetUsageTimeseriesAsync`, reuses `ProjectResolutionEndpointFilter` for auth.
  - Wrote 8 xUnit integration tests in `AgentUsageTimeseriesApiSpecs.cs` covering: response structure, bucket totals, completed sessions, empty buckets, sessions without usage, currency echo, unknown project 404, and sessions outside range.
- Files changed:
  - `packages/server/src/Mohist.Server/Sessions/Services/AgentSessionQuery.cs` — added `from`/`to` params; fixed callers to use named `ct:`.
  - `packages/server/src/Mohist.Server/Workflow/Services/Sessions/AgentSessionReadModels.cs` — added `AgentUsageTimeseriesDto`, `UsageBucketDto`.
  - `packages/server/src/Mohist.Server/Workflow/Services/Sessions/AgentSessionQuerier.cs` — added `GetUsageTimeseriesAsync`, `HasUsage`, `UsageBucketData` helper class; fixed `ct:` param.
  - `packages/server/src/Mohist.Server/Api/AgentRoutes.cs` — added `/usage` route.
  - `packages/server/tests/Mohist.Server.Tests/Specs/Api/AgentUsageTimeseriesApiSpecs.cs` — new test file.
- **Learnings for future tasks:**
  - `AgentSessionRow.CreatedAt` is set from `session.Status.CreatedAt` in `AgentSessionJson.ToRow` — DB filter and in-memory bucketing are consistent.
  - When adding parameters to `ListByLabelsAsync`, existing positional callers for `ct` break — use named `ct:` parameter.
  - The `AgentSessionQueryMetadataKeys.ProjectId` constant (`"mohist.io/project-id"`) is the label key for project-scoped queries.
  - Test helper inserts both `AgentSessionRow` and `AgentSessionLabelRow` — both needed for label-based queries to work.
  - `AgentSessionJson.JsonOptions` must be used for serialization to ensure DB deserialization (`AgentSessionJson.Deserialize`) can read it back.
- **Client selector pattern**: Follow the existing `useActivityCards` pattern — import `useAgentActivity`, wrap computation in `useMemo`, export a pure computation function for testability. Location: `widgets/coder-session/model/`.
- **Component test pattern**: Use `@vitest-environment jsdom` directive, `@testing-library/jest-dom` imports, `@testing-library/react` render/screen, and `MemoryRouter` when components use routing hooks.
- **Cost/Token formatting**: Use `formatCompact` for token counts (e.g. 1500 → "1.5k") and `formatCost` for cost amounts (e.g. 0.18, "USD" → "$0.18") from `shared/lib/format-compact`.
- **Vitest module mocking**: When mocking hooks from other files, use `vi.mock()` with relative paths. For pure-function unit tests, extract the computation function and test it directly without React/mocking.

## Task T-002: Client: activity-window usage snapshot selector + scope label
- What was implemented:
  - Added `computeUsageSnapshot()` pure function and `useActivityUsageSnapshot()` hook in `widgets/coder-session/model/usage-snapshot.ts`:
    - Sums additive fields (`inputTokens`, `outputTokens`, `totalTokens`, `costAmount`) from `useAgentActivity().sessions[].usage`.
    - Treats null/missing as zero; skips sessions without usage.
    - Excludes non-additive fields (`contextWindowUsed`, `contextWindowSize`, `contextUsagePercent`, `healthStatus`, `cachedReadTokens`, `thoughtTokens`).
    - Echoes `costCurrency` from first non-null session.
    - Computed entirely in `useMemo` — no additional network request.
  - Added `UsageSnapshotLabel` UI component in `widgets/coder-session/ui/UsageSnapshotLabel.tsx`:
    - Shows formatted token/cost totals using `formatCompact`/`formatCost`.
    - Always displays "activity window only" scope qualifier.
    - Never labels as project-total, weekly-total, or all-time.
  - Added 10 unit tests in `usage-snapshot.test.ts` covering: sum across sessions, empty array, missing usage, null fields, undefined fields, non-additive field exclusion, costCurrency echo, null costCurrency fallback, and no-throw for invalid inputs.
  - Added 7 component tests in `UsageSnapshotLabel.test.tsx` covering: scope label visibility, token display, cost display, no project-total/weekly-total/all-time labels, and zero-data fallback.
- Files changed:
  - `packages/web/src/widgets/coder-session/model/usage-snapshot.ts` — new file.
  - `packages/web/src/widgets/coder-session/model/usage-snapshot.test.ts` — new file.
  - `packages/web/src/widgets/coder-session/ui/UsageSnapshotLabel.tsx` — new file.
  - `packages/web/src/widgets/coder-session/ui/UsageSnapshotLabel.test.tsx` — new file.
- **Learnings for future tasks:**
  - `useAgentActivity()` returns `{ data }` where `data` has `sessions: AgentActivitySession[]` and each session has optional `usage?: AgentSessionUsage`.
  - `AgentSessionUsage` fields are all `number | null | undefined` — must use `?? 0` for safe addition.
  - `formatCompact(1500)` returns `"1.5k"` — tests must match formatted output, not raw values.
  - Extracting a pure `computeUsageSnapshot(sessions)` function makes the hook independently testable without React/mocking; this pattern can be applied to other selectors.
  - The `@vitest-environment jsdom` directive at the top of `.tsx` test files is required for DOM-based rendering tests.
