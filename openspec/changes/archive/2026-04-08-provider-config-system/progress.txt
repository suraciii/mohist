## 2026-04-08 — T-002: 实现 ConfigLoader — 加载、解析、校验、合并 config.jsonc
- Created `packages/cli/src/config/config-loader.ts`:
  - `load(configPath?)`: reads ~/.mohist/config.jsonc, parses JSONC via jsonc-parser, validates with Zod ConfigInfoSchema. Returns `{}` when file missing.
  - `getProviderConfig(config, providerID)`: resolves apiKey (config > env var) and baseURL (config > builtin), returns ResolvedProvider with source tracking.
  - `writeConfig(config, configPath?)`: atomic write via tmp file + rename, permissions 0600.
  - `ensureConfigDir()`: creates ~/.mohist/ with 0700 permissions.
- All 9 acceptance criteria verified, typecheck passes.
- **Learnings**: jsonc-parser's `ParseError.offset` is character-level, used `raw.substring(0, offset).split('\n').length` for line numbers. For unknown providers, `getProviderConfig` defaults to `openai-compatible` sdk — this aligns with T-003's requirement. The `source` field on ResolvedProvider will be useful for the `mo providers list` command (T-005) to show where apiKey comes from.
