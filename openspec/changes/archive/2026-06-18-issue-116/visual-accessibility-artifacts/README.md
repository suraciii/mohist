# Settings Visual Accessibility Artifacts

Generated by `npm run test:run -- settings-visual-accessibility-evidence.test.tsx`.
The `*-before.txt`, `*-after.html`, and `*-visual-diff.txt` files are deterministic Before/After visual evidence for the six Settings tabs.
`contrast-audit.json` records computed WCAG AA contrast ratios from project CSS color values used by the Settings text tokens.
