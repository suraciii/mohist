## 2026-03-28T12:00:00Z - T-006: Implement spawn_agent tool

**Status**: Completed

**What was done**: Created `tools/spawn-agent.ts` with `createSpawnAgentTool(defaultCwd?)` factory function. The tool:
- Uses `Tool.define()` from agent-runtime to create an AI SDK-compatible tool
- Parameters: `{ agent_type: string, task: string, cwd?: string, timeout?: number }`
- Spawns `opencode agent --local --message <task>` as a subprocess
- Captures stdout/stderr via piped stdio
- Implements timeout (default 30 min) with SIGTERM → 5s grace → SIGKILL escalation
- Returns formatted result: success with stdout, or error with stderr/exit code

**Key decisions**:
- Factory function `createSpawnAgentTool(defaultCwd?)` allows injecting worktree path at creation time (T-009 will wire this)
- `runSubprocess` is a standalone async function, not a class — simpler than the old `AgentRunner` class since we don't need multi-process tracking in M1
- Reused timeout + SIGTERM/SIGKILL escalation pattern from existing `agent/runner.ts`

**Learnings**:
- `Tool.define()` return type is generic `ToolInstance<P>` — need explicit `ToolInstance<any>` annotation on factory return type to avoid TypeScript variance error
- `ChildProcess` type import was unnecessary (we only use `spawn`, not the `ChildProcess` type directly)
