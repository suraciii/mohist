## Codebase Patterns

- Executor tests use `verifyOnlyWorkspaceManager` + `nonGitRunner` pattern (from executor-recovery.spec.ts, executor-task-log.spec.ts). The nonGit runner returns `{ success: false, stderr: "not a git repository" }`, which makes `readWorktreeSnapshot` treat the directory as clean-by-default and `checkBranchStability` return `{ kind: "ok" }`.
- Actions capture context in tests by registering a `registry.register("test/capture-context", async (ctx) => { capturedContext = ctx; return { status: "success" } })` handler.
- `baseContext()` in executor.ts returns `Omit<ActionContext, "with" | "workDir">`, so `with` and `workDir` (and now `rawWith`) are supplied inline at the call site.
