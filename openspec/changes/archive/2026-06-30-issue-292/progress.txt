## Codebase Patterns

- BarSeries uses transform: scaleY() + transformOrigin at bottom + useReducedMotion() for animation
- Segments are bottom-anchored <rect> elements sharing the same x/width within a bar
- Colors via className (fill-chart-*, stroke-chart-*), never fill/stroke attributes
- Chart primitives accept plotX/plotY/plotWidth/plotHeight for the plot area
- Zero-value handled via scaleY(0) keeping the rect present
- Test setup: setPrefersReducedMotion(bool) from ../../../../tests/setup
- Test convention: svg wrapper around primitives, data-testid assertions

## T-001 Implementation Notes

- SegmentedBarSeries accepts a caller-supplied max (not auto-computed) — this differs from BarSeries which computes max from data internally
- Each datum has ordered segments array with { value, fill }; all segments scale against the single max
- Zero-value segments render scaleY(0) rect (not omitted) — critical for "zero-completed day with failures" scenario
- All existing BarSeries/CostTrendChart tests remain green (D2 respected)
- Export added to charts/index.ts alongside BarSeries

## T-003 Implementation Notes

- ThroughputChart composes SegmentedBarSeries (completed=fill-chart-2, failed=fill-chart-4) and LineSeries (7-day MA via computeMovingAverage over completed only, stroke-chart-5)
