- `npm run build` (tsc) passes cleanly

**Learnings**:
- `ndJsonStream(output, input)` — output is writable (TO agent/stdin), input is readable (FROM agent/stdout)
- Zod v4 `z.record()` requires `(keySchema, valueSchema)` — two args, not one
- `ClientSideConnection` constructor takes `(toClient, stream)` where `toClient` is a factory `(_agent) => Client`
- `Client` interface requires `sessionUpdate` and `requestPermission` methods at minimum
- `requestPermission` auto-approves `allow_once`/`allow_always` options (needed for tool execution in opencode)
