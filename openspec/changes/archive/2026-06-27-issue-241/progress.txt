# Issue 241 progress

## Codebase Patterns

- CLI command groups follow `BuildXXX(api)` returning `Command`, registering subcommands via `command.Subcommands.Add(...)`.
- Issue subcommand paths use `ProjectIssuesPath(resolvedProjectId, $"/issues/{MohistCliCommands.Escape(number!)}/...")`.
- GET verbs route through `api.PrintWithOutputAsync(path, mode, nameof(MohistCliApi.TableShape.XXX))`.
- POST verbs route through `api.PrintPostWithOutputAsync(path, body, mode, nameof(MohistCliApi.TableShape.XXX))` with an empty `new { }` body when the server ignores the body.
- Table renderers live in `TableRenderer.Issues.cs` as `private void RenderXXX(JsonNode? data)` and are dispatched from `TableRenderer.Render` switch.
- Output mode defaults to `json`; `-o table` triggers the shape-specific renderer; `-o json` prints the raw envelope data via the shared `PrintEnvelopeAsync` path.
- The existing `PrintEnvelopeAsync`/`PrintResponseAsync` pipeline already surfaces structured errors (code + message) on stderr with non-zero exit (1 for conflict, 4 for not found). No dedicated 409 plumbing is needed as long as we don't short-circuit before the envelope parser runs.

## Gotchas / Decisions

- No `packages/cli/Mohist.Cli.sln` exists; build the CLI via `dotnet build packages/cli/Mohist.Cli/Mohist.Cli.csproj` or `dotnet build Mohist.sln -p:SkipWebBuild=true`.
- The singular `session` group and plural `sessions` list command are distinct System.CommandLine commands, so they coexist without collision.
- For `compact`/`reset`, the prominent `New session: <id>` line must use the recovery result's `agentSessionId` field, which is the new follow-on runtime session id, not the logical `id`.
- Transcript table mode renders a summary (turn count, part count, first/last activity) only; `-o json` preserves the full raw payload.
- Help text for the `session` group and each verb documents that `<name>` comes from `mo issue sessions <num>`.
- Tests mirror `CliEpicCommandSpecs`: `RecordingHttpHandler` + `FakeFileSystem` with active project state, then `MohistCliCommands.RunAsync`.
- When returning different anonymous payload shapes from a test responder, cast the ternary to `object` to avoid CS0173.
