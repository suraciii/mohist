## Codebase Patterns

- `MohistDbContext` exposes `WorkflowRuns` (rows) and `WorkflowRunTaskMaps` (`IDbContextFactory<MohistDbContext>` for hand-rolled tests). `ETag` is a shadow property accessed via `db.Entry(row).Property<long>("ETag")`. Bump pattern: `etag.CurrentValue = etag.OriginalValue + 1`.
- Spec test scaffolding (`TestSqliteDatabase.CreateMigrated`, `TestDbContextFactory`, `NullDispatchGrainFactory`, `Mohist.Server.Infrastructure.BackgroundTaskLauncher`, `RecordingEventStore`) lets the upgrader and store tests run without an Orleans silo.
- `MigrateLegacyWorkflowRunJson` lives on `WorkflowRunStateDataUpgrader` as `internal static` — tests reach it via `InternalsVisibleTo`. The compile-time gate enforces "only the cold-start migration boundary calls it"; future read paths cannot reintroduce a call without a deliberate visibility change.
- WorkflowRun reads use `JSON.Deserialize<WorkflowRun>` directly (no legacy converter in `WorkflowRunStore.Deserialize`). Read path remains correct (and redundant) after T-001 because the read path no longer invokes the converter — only `WorkflowRunStateDataUpgrader` does.

- Preflight collects diagnostics by `WorkflowRunId`, throws on any failure with all names listed, and writes nothing.
- Backup: `CreateAndVerifyBackupAsync` uses `source.BackupDatabase(destination)`, runs `PRAGMA integrity_check`, rejects `:memory:` / `Mode=Memory`, and rejects bare `.db` copies. `UpgradeAsync` opens the source only as needed and restores prior `Open` state.
- Commit phase: single `db.Database.BeginTransactionAsync` over chunked fetches (`Chunk(500)`); ETag incremented via `CurrentValue = OriginalValue + 1`. Any save error rolls back the whole transaction.
- Idempotency: ordinal string comparison between converted and original State; canonical rows skip the upgrade and never bump ETag. Re-running reports `CandidateCount=0`, `WrittenCount=0`, `BackupPath=null`.
- No lifecycle filter — `failed` runs migrate identically (covered by `WorkflowRunRerunMigrationSpecs`).
