## T-005 — 提取连接存活/重连 helper 到 liveness-probe.ts

- Created `packages/runner/src/server/liveness-probe.ts` with three free-function exports (verbatim ports from `runner-signalr.ts`):
  - `probeLiveness(connection, probeTimeoutMs, signal)` — settle-once idempotent, abort-at-call-time aware, non-Connected short-circuits without invoking `Ping`, single `Promise<boolean>` race between `Ping.then/catch`, `setTimeout`, and the `abort` event listener.
  - `forceReconnect(connection, onReconnected, signal)` — Disconnected → straight `start`; otherwise `stop` → `start` with `try/catch` swallowing the stop error so the subsequent `start` surfaces the real state; post-stop `signal.aborted` short-circuits `start`; successful `start` notifies via `notifyReconnected`.
  - `notifyReconnected(connection, onReconnected, connectionId?)` — prefers a non-empty `connectionId` arg, falls back to `connection.connectionId`, returns silently when either is empty or no callback is registered.
  - The module imports `import * as signalR from "@microsoft/signalr"` (NOT `import type`) because it references `signalR.HubConnectionState.Connected` / `.Disconnected` at runtime — a `import type` would fail typecheck under `HubConnectionState cannot be used as a value`. The `signalR` import brings in the full `@microsoft/signalr` namespace types plus the `HubConnectionState` enum constant.
  - `OnReconnectedCallback = (connectionId: string) => void` is exported as the shared shape so the helpers don't depend on the `RunnerSignalRClientOptions` interface.
- `packages/runner/src/server/runner-signalr.ts` (595 → 555 lines, −40 net: 8 lines added for the new import, 49 lines removed for the four helper bodies + the private method):
  - Removed inline `probeLiveness` (28 lines), `forceReconnect` (16 lines), `registerLifecycleCallbacks` (4 lines — kept, but body now delegates to the free `notifyReconnected`), and the private `notifyReconnected` (7 lines).
  - Added `import { forceReconnect, notifyReconnected, probeLiveness } from "./liveness-probe.js"`.
  - Public `client.probeLiveness(signal)` and `client.forceReconnect(signal)` are now 1-line delegations to the free functions; `connection` is `this.connection`, `onReconnected` is `this.onReconnected`, `probeTimeoutMs` is `this.probeTimeoutMs`. Byte-identical contract from the outside.

  - `runner-signalr.ts` re-exports unchanged (still does NOT re-export `probeLiveness` / `forceReconnect` / `notifyReconnected` — they're consumed via the class instance, not by import name; design.md D4 only mandates test-facing bindings get re-exported).
