## Codebase Patterns

- Server persistence uses `MohistDbContext` with explicit row mappings and migration-chain SQLite templates in SpecTests.
- Project-scoped API groups resolve the project through `ProjectResolutionEndpointFilter`; API errors use `ApiResults` and stable `Code` values.
- Agent state is stored as JSON in `AgentRow`; `AgentQuerier.GetByIdAsync` is the existing project/status lookup used for routing-rule validation.
- Event match validation uses `EventMatchExpression.Compile`, whose `MatchDiagnostic` contains offset, line, and column. The API reuses the `invalid_match_expression` code and exposes these fields.
