## Codebase Patterns

- CLI command groups are registered from partial `MohistCliCommands.*` files; removing a subtree requires removing its registration and implementation file so retired forms use standard unknown-command parsing.
- CLI contract tests use `CliTestFactory` and `RecordingHttpHandler` to assert both exit codes and no HTTP dispatch.
- Run detail remains implemented by `RunCommands.RegisterReads` through `BuildView`; no changes were needed to target resolution or the WorkflowRun detail DTO.
