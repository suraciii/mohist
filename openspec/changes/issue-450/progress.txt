## Codebase Patterns

- T-001 is the only task permitted to import or construct the real Pi SDK. Product runtime code must remain absent until this gate is complete.
- The Runner workspace uses the root lockfile; dependency changes are made with `npm install -w packages/runner`.
- Pi SDK 0.80.10 requires Node >=22.19.0. The repository uses Node 22.19.0 as its concrete supported release.
- SDK project trust is fixed with `SettingsManager.create(cwd, agentDir, { projectTrusted: false })`; the same settings manager and explicit `cwd` / `agentDir` are passed to `DefaultResourceLoader` and `createAgentSession`.
- SDK `prompt()` expands file prompt templates by default. Literal Workflow input requires `{ expandPromptTemplates: false }`.
- SDK `abort()` returns `Promise<void>` and has no separate stop-confirmation operation; stop confirmation observes `isStreaming` and session events.
- `SessionManager.create(cwd, sessionDir?)` and `SessionManager.open(sessionFile)` expose the persisted absolute session path through `session.sessionFile` / `getSessionFile()`.
- SDK custom tools can run headlessly with `noTools: "builtin"`; no per-tool approval callback or confirmation state is involved.
