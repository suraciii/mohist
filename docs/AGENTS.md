# Writing User Guides

`docs/` holds the product vision, conceptual reading guide, tutorials, and
operating guides. Write for people and Agents who do not read the source code.

- Follow the [shared writing rules](../eng/context-management.md#writing-rules).
- Explain the user task and reading order. Link to the owning feature in
  `specs/` for behavior, safety boundaries, and acceptance rules.
- Do not create feature specifications or duplicate their bodies here.
- Keep the README for human navigation, not Agent instructions or a spec catalog.
