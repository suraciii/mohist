# 外部 Agent 调用

外部调用者将能够用 Mohist 的个人访问令牌，直接委托一个已配置好的 Mohist Agent，并在网络中断后继续确认这次委托是否被接受、正在进行或已经结束。

这条调用路径只适用于私有 Project。它不改变 Agent 的身份、配置、并发规则或会话语义；同一个 Agent 无论从 Web、CLI、自动化脚本还是外部调用进入，都会使用同一份工作与会话记录。

## 谁可以调用

- 调用者必须使用自己的有效个人访问令牌；没有令牌、令牌无效或没有该 Project 权限时，Mohist 不会接受任何委托。
- 只读令牌可以查看已知工作的公开进度和结果；能够启动、继续或停止工作的令牌需要操作权限。
- 本版本不新增多人之间的可见性规则。私有 Project 仍由现有拥有者模型保护。

## 提交与继续

- 每次启动新工作或继续已有会话，调用者都提供一个稳定的请求标识。
- 同一请求标识配同一内容，重复提交始终回到同一份工作、会话、输入和处理记录，不会启动第二次执行。
- 同一请求标识配不同内容会被明确拒绝；调用者必须使用新的请求标识表达新的意图。
- 启动新工作会建立一份工作和会话；继续会话只增加新的输入和处理，不会建立第二份工作。
- 已明确拒绝的请求会保留原结论。容量后来恢复或网络重连，都不会把它悄悄改成已接受。

## 查看进度

每条已知输入和处理记录都会返回一个明确状态：

| 状态 | 含义 |
|---|---|
| 已接受 | Mohist 已记录这次委托，正在决定或准备后续处理。 |
| 排队 | Mohist 已接受委托，正在等待可用处理能力。 |
| 执行中 | Agent 正在处理，或正在确认本轮结果。 |
| 已结束 | 这次处理已完成、失败、取消、被永久阻止，或在受理前被明确拒绝。 |
| 未知 | Mohist 暂时无法确认一次输入、停止或结果的事实；它不会把未知显示成空闲或成功。 |

“暂时阻塞”会单独说明：可恢复的排队阻塞仍是排队，永久阻止才是已结束。结果尚在确认时仍是执行中，不能据此开始另一项会与当前工作冲突的处理。

## 断线后恢复

- 每段会话提供按发生顺序连续的公开更新。调用者保存上次看到的位置后，可以从其后继续读取，不需要再次提交任务内容。
- 重复收到同一条更新或并发读取时，调用方可以按其稳定顺序去重；到达较晚的更新不会改写已经确认的结束结论。
- 位置无效时，Mohist 会明确报错；位置已经过期时，调用者先重新读取当前状态，再从保留的历史继续。Mohist 不会把它静默重置到另一段历史。

## 停止与未知结果

- 调用者只能请求停止一个已知的当前处理，不能直接控制执行机器或运行环境。
- 已经结束的结论优先于晚到的停止或完成通知，结果和公开更新不会被回写成另一种状态。
- 停止结果或执行结果未知时，Mohist 保持“未知”并阻止自动重放。调用者应重新查看该处理，而不是重复提交原任务。

## 可见内容

外部调用只会看到稳定的工作、会话、输入和处理标识，以及公开状态、结果、错误说明、时间和进度顺序。

它不会返回 Agent 的隐藏指令、记忆、运行位置、执行机器身份、内部连接、原始请求内容或原始运行记录。受控诊断和完整会话记录仍使用各自的产品入口，不会因为外部调用而自动公开。
