## 关于本文档

- **当前事实**：文档里写的都是当前版本真实可用的能力
- **不写愿景**：还没实现的功能不会出现在文档里
- **示例可复制**：所有命令、配置示例都经过验证

文档随版本演进，发现过时描述欢迎提 issue。
